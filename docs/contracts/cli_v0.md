# Contrato CLI v0 (congelado)

## Nombre canónico
- Ejecutable oficial: `app`.

## Flujo MVP obligatorio
- `app models search`
- `app models add`
- `app run chat`
- `app jobs list`
- `app jobs info`

## Regla de compatibilidad
- En v0 no se permiten cambios breaking en:
  - nombres de comandos,
  - nombres de flags,
  - estructura de salida JSON.
